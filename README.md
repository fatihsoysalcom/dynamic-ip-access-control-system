# Dynamic IP Access Control System

This Python script demonstrates a dynamic IP access control system, moving beyond static, individually managed whitelists. It simulates how a system can automatically manage access based on multiple rules, including a core whitelist, trusted network ranges, and a temporary blocklist, reflecting a paradigm shift towards smarter access management.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
